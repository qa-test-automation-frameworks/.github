Lower the cap without breaking old clients

The Quality Reference Application added a $5,000 API v2 policy limit while keeping the existing $10,000 API v1 contract. A deliberate red control proved the old boundary was protected; the repair passed the PostgreSQL verification gate.

Business risk
Changing v1 in place would reject claims that existing clients could submit before.
Detecting control
The preserved v1 boundary test failed when the limit was deliberately changed, then passed with additive v2.
Compatibility boundary
The product release passed QRA verification. Consumer evidence is tied to its exact image digest; the target record carries those pins and limits.
