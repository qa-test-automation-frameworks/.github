## R02 findings and disposition

- The DiskCache exception concerns pickle deserialization in an optional cache
  backend that this repository does not instantiate. The review judged current
  exposure low, while identifying the risk of a future cache integration or
  unsafe cache reuse.
- The RAGAS advisory record was incomplete: the advisory includes local-file
  processing as well as URL processing, and RAGAS 0.4.3 also contains a
  multimodal-relevance path to the helper. The current project factories use
  text metrics and do not invoke those multimodal paths.
- Both optional semantic dependencies were included in the packaged image by
  `uv sync --all-extras`, although the image's default command runs Tier-1
  checks. The runtime image can omit the semantic extra while semantic CI
  installs it separately.
- The exception record's statement about excluded severity classes did not
  match the Trivy `CRITICAL,HIGH` threshold. `pip-audit` remains the gate that
  sees these exact low/medium Python findings.
- The expiry validator did not require a reviewer/date record, cap the review
  window, or run on a daily schedule. Multiple IDs could inherit one expiry.
- The reviewer recommended retaining the two exact exceptions only through
  their current expiry, adding controls, and not extending them without a new
  documented decision. The owner accepts that bounded disposition; this does
  not clear either advisory or authorize renewal.
